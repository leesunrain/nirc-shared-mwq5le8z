검증: 기존 URL에서 v1.1 표시, 계산값, 그래프, PWA 바로가기, 사용자 데이터 보존 여부 확인. 이 앱 자체는 입력값을 영구 저장하지 않습니다. 서비스워커는 최신 캐시를 사용하며 localStorage/IndexedDB를 삭제하지 않습니다.

주의: 85/65/40%는 연구 원칙을 참고한 설계 예시이며 연구로 검증된 유일한 최적 비율이 아닙니다.
